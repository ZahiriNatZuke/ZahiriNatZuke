## About

- I build web applications end to end: Angular frontends with signals and NgRx SignalStore, and NestJS backends on Fastify with Prisma and PostgreSQL.
- I maintain open source templates for both sides of that stack, with security, testing and CI set up from the start.
- Lately I build MCP servers and tooling for AI coding agents such as Claude Code and Codex.
- The best way to reach me is LinkedIn.

## Featured projects

**[local-delegate](https://github.com/ZahiriNatZuke/local-delegate)** &nbsp;
<a href="https://pypi.org/project/local-delegate-mcp/"><img src="https://img.shields.io/pypi/v/local-delegate-mcp?style=flat&label=PyPI" alt="PyPI version" /></a><br/>
MCP server that hands mechanical text tasks (summaries, extraction, lint and test digests, commit messages, code explanations) to a local OpenAI-compatible model, so the coding agent spends less of its context and quota. Works with Claude Code, Codex and opencode, ships hooks and a skill, and includes a dashboard that measures the savings. Python, published on PyPI.

**[angular-template-project](https://github.com/ZahiriNatZuke/angular-template-project)**<br/>
Angular starter with zoneless change detection, NgRx SignalStore, HttpOnly cookie authentication, Tailwind CSS and i18n, tested with Vitest and Playwright.

**[nest-template-project](https://github.com/ZahiriNatZuke/nest-template-project)**<br/>
NestJS starter on Fastify with Prisma, Passport (JWT, API keys and TOTP two-factor authentication), Pino logging and Zod validation, with Docker and a Jest test suite.
